# My Portfolio

A clean, modern developer portfolio built with React and Vite.

## Design

The portfolio follows the rules defined in [`DESIGN.md`](./DESIGN.md):

- Dark slate background: `#0F172A`
- Slate project cards: `#1E293B`
- Off-white text: `#F8FAFC`
- Sky-blue accent: `#38BDF8`
- Responsive hero section
- Responsive GitHub project grid

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Customize

Open `src/App.jsx` and replace:

- `Your Name`
- Your bio
- GitHub URL
- LinkedIn URL
- Project names
- Project descriptions
- Technologies
- Repository links

You can also use `projects.txt` as your project information checklist.

## Deploy

This project can be deployed using GitHub Pages, Vercel, or Netlify.
