# Portfolio Design System

## Overview
A clean, modern developer portfolio showcasing my GitHub projects.

## Colors
- background #0F172A (Dark slate)
- card-bg #1E293B (Lighter slate for project boxes)
- text #F8FAFC (Off-white)
- accent #38BDF8 (Bright sky blue for links and buttons)

## Layout & Components
- Hero Section: Simple intro with your name, a short bio, and links to GitHub/LinkedIn.
- Project Grid: A responsive grid showing project cards. Each card must include the repo name, description, primary programming language, and a link to GitHub.
